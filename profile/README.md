# Welcome to A Cloud Center

A Cloud Center is my space for building projects, solving real problems, and experimenting with new ideas. I spend my time creating systems that bring together cloud infrastructure, automation, Python, React, and AI with a strong focus on real time applications.

Most of my work today revolves around collaboration and voice technology. That includes building conversational agents, experimenting with and integrating voice models, pipelines, and underlying infrastructure. I also enjoy building useful tools from Cisco and SIP room systems.

# Collaboration Welcome

My space is open to anyone who wants to collaborate, share ideas, or work on fun projects together. If you are interested in voice technology, real time media, AI agents, or simply enjoy building new things, reach out!

# Security and Best Practices

In my pipeline I try to use various security tools and services such as linting, Prettier, Semgrep, and GitHub’s Advanced Security tools to keep code quality high and vulnerabilities low. This is not meant to be a production-grade Sec-Ops implementation, but rather some additional automated checks to help reduce any issues or vulnerabilities.
